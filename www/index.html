VIDEO 2: HOW IT WORKS — 4 MINUTES DEMO

Now let me explain 4 minutes how infinite call and chat works, you see me holding phone with voice waves. Step one, you tap START INFINITE CALL button. Browser calls navigator dot mediaDevices dot getUserMedia with audio true — it asks Allow microphone, you tap Allow. Step two, see screen behind me: Mic arrow to Speech Recognition API, I set continuous equals true and interimResults equals true — this means it listens forever, no 2 second cut, it keeps listening even when you pause. I also add silence timer 1.4 seconds: when you stop talking for 1.4 seconds, it auto sends your text to slash api slash chat. Step three, fetch to slash api slash chat with POST, body JSON with message and history last 8 turns, server calls Groq API openai gpt-oss-20b, super fast 0.8 seconds, plus Tavily web search if needed, returns reply. Step four, chat history saved in localStorage benvo34_history, rendered on screen as user and bot bubbles. Step five, Text to Speech via speechSynthesis dot speak, with utterance, it speaks answer with voice, onstart I stop recognition to avoid echo, onend if callActive true I call restartMic loop — this is the magic infinite loop arrow you see on screen — it restarts mic after speaking, so call continues forever until YOU tap END CALL when tired — you can talk 1 hour straight! Step six, daily ad logic: I use localStorage benvo_last_ad_date with today toDateString, so ad shows once per day, then disappears to chat, continuously every single day, tomorrow shows again. This is true phone call mode, not push-to-talk. Village built, world class technology from Maaya Lubimbiri Uganda. Thank you for watching 4 minutes!

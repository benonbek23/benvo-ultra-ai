⚙️ VIDEO 2: HOW IT WORKS (Tech Flow)

How Benvo Ultra Works:
🎤 You tap START INFINITE CALL → browser asks mic permission (navigator.mediaDevices.getUserMedia).
👂 SpeechRecognition (continuous=true) listens — no 2-sec cut, silence timer 1.4s auto-sends.
🧠 Text sent to /api/chat → Groq 20B answers in <1 sec + Tavily live search if needed.
🔊 Reply spoken via speechSynthesis → when speech ends, mic auto-restarts (restartMic loop).
♾️ Loop continues FOREVER until you tap END CALL. Chat history saved in localStorage.
Infinite call — goes until you get tired. Tap START.
